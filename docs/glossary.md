# Глоссарий

Термины проекта, чтобы все называли вещи одинаково.

| Термин | Значение |
|---|---|
| Единый чат | Главный интерфейс и единая точка входа: через него пользователь вводит любые данные |
| Общая база | Единое хранилище данных пользователя, общее для всех модулей |
| Модуль | Преднастроенное агентское «приложение» под одну сферу жизни (трекер, финансы…) |
| Агент | ИИ, который разбирает сообщения из чата, раскладывает данные по модулям и даёт рекомендации |
| Холодильник | Часть лайфстайла: учёт продуктов дома |
