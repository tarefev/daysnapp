## Правила

- В каждой папке есть `_template.md`: копируй его, когда заводишь новый файл.
- Имена файлов пиши латиницей через дефис: `slug-zadachi.md`.
- Задачи и баги начинай с номера issue: `42-login-form.md`. Если issue ещё нет, используй дату: `2026-10-21-crash-on-start.md`, а когда issue заведёшь, переименуй файл.
- Когда идея становится задачей, поставь в идее ссылку на файл задачи, а саму идею не удаляй.
