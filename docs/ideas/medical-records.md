# Идея: Медкарта

**Статус:** новая
**Дата:** 2026-10-21

## Суть
Медицинская информация человека в одном месте.

## Что входит
- Анализы: фото бланка → ИИ распознаёт показатели → динамика по времени
- Визиты к врачам, диагнозы, назначения
- Прививки
- Хронические заболевания, аллергии

## Зачем
Сейчас медицинские данные разбросаны по клиникам, бумажкам и чатам. Динамика анализов — сильный сценарий для ИИ-анализа.

## Открытые вопросы
- Как показывать врачу: доступ по ссылке, экспорт в PDF?
- Особо чувствительные данные: повышенные требования к приватности
