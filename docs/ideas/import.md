# Идея: Импорт данных

**Статус:** новая
**Дата:** 2026-10-21

## Суть
Сквозная механика ядра: перенос данных из других сервисов.

## Что входит
- Telegram (чаты с самим собой, «Избранное»)
- Apple Health, Google Fit
- Банки и выписки
- Другие трекеры

## Зачем
Человеку не нужно начинать с нуля: продукт с первого дня содержит его данные.
