# Идея: Маркетинг

**Статус:** обсуждается
**Дата:** 2026-10-21

## Суть
Две линии продвижения:
1. **Общая концепция:** одно приложение для всей жизни с единым чатом и общей базой.
2. **Отдельные модули как самостоятельные продукты,** чтобы привлекать людей через конкретную потребность. Кандидаты: упражнения + тренер/диетолог, трекер, фильмы.
