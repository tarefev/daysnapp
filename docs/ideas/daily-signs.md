# Идея: Карта дня, гексаграмма дня, гороскоп

**Статус:** новая
**Дата:** 2026-10-21

## Суть
Каждый день пользователь получает «знак дня»:
- карту дня (Таро);
- гексаграмму дня (И-Цзин);
- возможно, гороскоп.

## Зачем
Повод открывать приложение каждый день и маленький ритуал. Может зацепить более молодую аудиторию.

## Открытые вопросы
- Что из этого показывать по умолчанию, а что включается по желанию.
- Сохранять ли историю знаков, чтобы потом сопоставлять её с дневником и настроением.
