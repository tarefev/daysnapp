# Модуль: Фильмы

> ⚠️ **Сырой черновик.** Это набросок идеи с доски, а не решение и не спецификация. Всё здесь может поменяться или отпасть.

**Путь в коде:** —

## Назначение
Список того, что интересно посмотреть, и того, что уже посмотрено. Агент даёт рекомендации прямо на главном экране («Посмотри Бойцовский клуб»).

## Возможное расширение
На доске рядом есть пункт «музыка, которую нравится слушать, книги»: этот модуль можно сделать общим для медиа.
