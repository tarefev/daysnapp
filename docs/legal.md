# Юридическая модель и юрисдикция

> ⚠️ Это рабочие допущения команды и ориентиры из обсуждения, **не юридическая консультация**. Перед публикацией и перед подключением медицинских модулей всё нужно проверить у юриста по персональным данным и у налогового консультанта: законы, штрафы и правила платформ часто меняются.

**Дата:** 2026-10-21

## Текущий план (старт)
- Публикуемся как **частное лицо** (индивидуальный аккаунт разработчика), без компании.
- **Российский рынок не целевой.** Россия убрана из списка стран в App Store и Google Play.
- **Медицинских данных на старте нет.** Медицинские модули подключаем, когда появятся пользователи, компания и юридическая поддержка.

## Что можно на старте, а что откладываем

| Можно | Серая зона | Откладываем |
|---|---|---|
| Еда, калории, БЖУ, вода | Вес и цели по весу (по GDPR могут считаться данными о здоровье) | Медкарта, анализы |
| Фильмы, места, финансы для себя | Шаги, сон, активность из HealthKit — можно при соблюдении правил ниже | Лекарства, болезни |
| | | Менструальный цикл |
| | | Психолог, эмоциональный дневник |
| | | Документы |

Первая версия позиционируется как «питание и калории», а не как «здоровье».

## Условия даже для частного лица
1. **Россия исключена** из стран распространения, нет оплаты в рублях и рекламы в РФ, в условиях использования указано, что сервис не предназначен для резидентов РФ.
2. **Политика конфиденциальности.** Требование Apple; обязательна и по GDPR при пользователях из ЕС.
3. **Удаление аккаунта и данных** прямо из приложения (требование Apple).
4. **Договор между основателями.** Простой письменный: права на код и бренд, распределение дохода, что происходит при выходе одного из участников.
5. **Доступ к ИИ-провайдеру.** Проверить условия Anthropic для частного лица в Индонезии. Оплата — картой не российского банка.
6. **Налоги и виза.** Проверить налоговое резидентство (183 дня) и то, что виза в Индонезии позволяет получать доход.

## HealthKit (шаги, сон, активность)
Использовать можно, в том числе частному лицу. Условия Apple (раздел 5.1.3 App Review Guidelines):
- данные нельзя использовать для рекламы, маркетинга и продажи — только для функций приложения;
- передача третьим лицам (в том числе ИИ-провайдеру для анализа) — только с явного согласия пользователя и с описанием в политике конфиденциальности;
- нельзя хранить медицинские данные в iCloud;
- при запросе доступа нужно конкретно объяснить, зачем он нужен;
- запрашивать только нужные типы данных.

Дополнительно: перед подключением HealthKit показываем **отдельный экран согласия**, потому что по GDPR шаги и сон, вероятно, относятся к данным о здоровье.

## Почему не российский рынок (справочно)
- **Локализация (152-ФЗ, ст. 18 ч. 5).** Первичная база персональных данных граждан РФ должна находиться в РФ. Закон распространяется и на иностранные компании, которые ориентируются на российских пользователей. Признаки ориентации: российский стор, рубли, реклама в РФ, домен `.ru`.
- **Данные о здоровье — специальная категория** (ст. 10): нужно письменное согласие и усиленная защита.
- **Трансграничная передача** (например, в ИИ за рубежом) требует предварительного уведомления Роскомнадзора. США не входят в список стран с «адекватной защитой».
- **Западные ИИ-провайдеры (Anthropic, OpenAI) не обслуживают Россию.** Альтернативы — российские модели (YandexGPT, GigaChat) или открытые модели на своих серверах в РФ.
- **Реестр ОРИ.** Если пользователи могут переписываться (соцсеть), сервис может попасть в реестр организаторов распространения информации с обязанностью хранить переписку и предоставлять ключи шифрования.

## Когда понадобится компания
- Перед подключением медицинских модулей: Apple требует публиковать приложения со здоровьем и другими чувствительными данными от юрлица.
- При двух и более участниках с долями, при инвестициях, при росте объёма данных (ответственность частного лица — личная).
- Переход возможен без потери пользователей: в App Store есть перенос приложения на другой аккаунт (App Transfer).

### Варианты юрисдикции для обсуждения
ОАЭ (фри-зоны), Кипр, Сербия, Армения, Грузия, Казахстан (Astana Hub), США (Delaware LLC). У каждого варианта свои налоги, банки и отношение к гражданам РФ. Эстонская e-Residency гражданам РФ сейчас недоступна.

Отдельно проверить: условия Anthropic для компаний, которыми владеют граждане РФ, живущие за рубежом.
